# Aurora documentation

Aurora's mission is pure object oriented programming: zero primitives, with everything expressed as an object or a method. This guide explains both the language's direction and the builtin features available in the current interpreter.

## Learn Aurora

| --- | --- |

| [Getting started](getting-started.md) | Build the interpreter and run your first `.aur` script. |
| [Syntax and style](syntax.md) | Method calls, semicolons, blocks, literals, and naming. |
| [Variables and constructors](objects.md) | The difference between `.create()`, `.new()`, and `.set()`. |
| [Control flow](control-flow.md) | `Logic.if`, `.else`, `Loop.while`, and `Loop.for`. |

| [Examples](examples.md) | Complete programs and links to the repository's examples. |
| [Status and limitations](status.md) | Incomplete features, compatibility notes, and the project map. |

Code fences marked `aurora` contain Aurora source. Reference signatures use `...` for multiple arguments and `→` for a result type; these are documentation notation. Examples labelled as intended syntax illustrate features with known implementation limitations.
